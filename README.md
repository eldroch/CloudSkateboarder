# 🐱 Cloud Skateboarder 🛹

Play as a cool grey cat in sunglasses, shredding through levels on a skateboard
to earn **cat food** and **cat treats**!

## How to Play

Just open `index.html` in any modern browser — no install, no build step.

Or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Controls

| Key | Action |
| --- | --- |
| `←` `→` or `A` `D` | Skate left / right |
| `Space`, `↑`, or `W` | Ollie (jump) |
| `P` | Pause |

## The Rules

- 🐱 You start with **exactly 5 hearts** (your lives/HP).
- 🛹 **Ramps boost your speed** — hit them fast and launch!
- 🐶 **Dogs**, 💧 **water puddles**, and 🚿 **water sprayers** each cost you a heart.
  (Pro tip: you can stomp dogs from above, and jump over puddles.)
- 🍖 Finish a level and earn **10 cat food / cat treats**.
- 🥫 Grab cat food cans mid-level for bonus treats.
- ❤️ In the menu, spend **30 cat treats** to upgrade your max HP by one heart —
  all the way from 5 hearts up to **10 hearts**.
- 💾 Your treats, hearts, and unlocked levels save automatically.

## Levels

1. **Sunny Sidewalk** — learn the ropes
2. **Park Path** — first sprayer appears
3. **Backyard Blitz** — sprinklers heat up
4. **Dog Park Dash** — so many dogs
5. **Sprinkler Splash** — stay dry if you can
6. **Rooftop Rush** — the ultimate gauntlet
